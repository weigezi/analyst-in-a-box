# Security

[中文](SECURITY.zh.md)

The skill's scripts read your data and write only inside the workspace folder you give them. The scripts make no
network calls of their own. Your AI tool reads what they print and sends it to its model provider. If you find a way for it to read or write elsewhere, or to leak data, please open a private security advisory on
GitHub (Security tab, "Report a vulnerability") instead of a public issue.
