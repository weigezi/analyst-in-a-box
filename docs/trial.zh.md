# 试用者说明

[English](trial.en.md)

谢谢你拿自己的生意来试 analyst-in-a-box。这个项目目前只在它自己的演示数据上测过，你的评价才是真正的检验。
第一天大约一小时，之后每次几分钟。

## 1. 你需要

- 一个能加载 Agent Skills（一个带 `SKILL.md` 的文件夹）的 AI 工具，并且它能用终端。
- Python 3.10 或以上；缺 `pandas`、`pyyaml`、`openpyxl` 的话，工具会自己装。
- 一张你自己的表：订单、发票或者每天的汇总都行，要有一列日期、至少一列金额。CSV、Excel、SQLite、DuckDB 都可以。脚本在你的电脑上跑，你的 AI 工具会读到它打印出来的内容。
- 最好准备一个你已经知道答案的问题：过去某一周，你清楚它为什么变了。

## 2. 第一次

1. 把 `skills/analyst-in-a-box/` 复制到你的工具的 skills 文件夹里。
2. 用你自己的话问它，比如：「这是我们的订单表（路径）。上周营收为什么跌了？」
3. 它会问每一列是什么。照实回答；不是指标的列就说「不是指标」。
4. 读它给你的第一份报告。

## 3. 怎么评第一次的答案

| 问题 | 是 / 否 |
|---|---|
| 数对不对？（挑一两个和你自己的看板对一下。） | |
| 它有没有至少说出一件你之前不知道的事？ | |
| 它说「分散，没有单点」的地方，说得公道吗？ | |
| 它说「原因待你确认」的地方，是不是真的只有你才知道？ | |

## 4. 接下来一周

拿真实的问题去问它。它说错了，或者漏了你知道的东西，就像跟一个新来的分析师那样直接告诉它。它会把你的话记下来。
纠正过几次之后，再评一次：

| 问题 | 是 / 否 |
|---|---|
| 你纠正过的错，它有没有再犯？ | |
| 它现在的答案，是不是接近你们自己分析师会写的？ | |
| 它有没有把猜测说成事实？ | |

上面两张表，以及任何让你意外的地方。如果你愿意，再加上工作目录里的 `corrections.jsonl` 和 `runs/*/record.json`：
它们存的是你的纠正和每次运行算了什么，**不是你的数据**。发之前先看一遍，不想分享的就删掉。

## 6. 出了问题

- 你已经回答过某一列，它又问一遍：这是 bug，请记下是哪一列。
- 报告写着「交付前自检没通过」：它发现自己的数对不上，拒绝作答。请把那次运行的 `record.json` 发过来。
- 它没问就猜了一列的意思：这违反了它的第一条规矩，请把它的原话告诉我们。
