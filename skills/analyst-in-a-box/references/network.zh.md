# 知识页

[English](network.md)

`network` 把一个工作目录变成一张 HTML 页面 `knowledge.html`：会动的业务知识图谱。
它有两部分：指标树和业务世界描述。页面只读 `model.yaml` 和 `world.yaml`，里面有什么就画什么，自己不添加任何节点或说法。

目录：1 命令 · 2 画了什么 · 3 可信程度 · 4 怎么用 · 5 局限

## 1. 命令

```
python scripts/aib_cli.py network --workspace <dir> [--lang zh|en] [--out FILE]
```

写出 `<dir>/knowledge.html`，并打印两个视图各有多少个节点和连线。`--lang` 默认用工作目录的语言。
文件是自包含的：样式、脚本和数据都在里面，不联网，不用网络字体，可以直接从 `file://` 打开。
工作目录变了就再跑一次；页面从 YAML 重新生成，不手改。

## 2. 画了什么

| 视图 | 节点 | 连线 |
|---|---|---|
| 指标树 | 每个指标（北极星在最上面），以及切分顺序里出现过的每个维度 | 公式（`identities`：左边的指标连到每个因子，标 × 或 ÷），一直显示；切分顺序（`priorities`：指标连到维度，带序号），只在悬停、聚焦或点按的那张卡片上显示 |
| 业务世界描述 | 实体、机制、事件、动作 | 实体之间的 `relations`；每条机制、事件、动作连到它提到的实体 |

事件按开始日期被拉向一条日期轴。指标能切、但没有记录顺序的维度，只在详情面板里列出，不画。

## 3. 可信程度

节点或连线的档位只看它自己那条记录的 `source.kind` 和 `status`：

| 档位 | 规则 | 样子 |
|---|---|---|
| 事实 | `source.kind` 是 `user`、`system_record`、`data` 或 `formula`，且 `status` 是 `confirmed` | 实线轮廓、蓝色底、对勾 |
| 待确认 | `status` 是 `proposed`，或 `source.kind` 是 `document` | 虚线轮廓、「待确认」标记，面板里引用原句 |
| AI 推断 | `source.kind` 是 `general_knowledge` 或 `demo_setting` | 点线轮廓、浅色底、「推断」标记 |
| 已作废 | `status` 是 `retired`（优先于其他档） | 灰色、加删除线 |
| 无出处记录 | 没有任何公式记录提到的指标；没有待人确认的说法 | 中性灰点划线轮廓、「无出处」标记 |

即使标了 `confirmed`，推断仍然是推断。没有可用出处的记录显示为「待确认」，绝不当事实。
指标自己没有出处：取它所在公式里最弱的一档，并在面板里写明。没有出现在任何公式里的指标显示为「无出处记录」：模型里用到了它，但没有任何记录说明它从哪来。维度取提到它的切分顺序里最弱的一档。
图例用大白话解释这几档，开关可以隐藏 AI 推断。

演示工作目录的设定（`demo_setting`）有意显示为 AI 推断，直到有人确认。

## 4. 怎么用

- 拖动卡片可以挪位置，布局会短暂升温再停下。拖动背景平移，滚轮或双指缩放。
- 点卡片或连线，或者 Tab 到卡片按 Enter：面板显示名称、种类、出处（记录里有就带原话和日期）、状态，
  设了 `refuted_by` 就显示「什么数据能推翻它」。
- 悬停或聚焦一张卡片，其余内容变淡，只留它的邻居。指标树里切分连线也是这样出现的，平时隐藏，公式树才看得清。面板里，指标列出切分顺序（「1 大区、2 渠道」），维度列出它切哪些指标、在各自顺序里排第几。Esc 关闭面板。
- 系统开启「减少动态效果」时，直接画出停稳后的布局。

## 5. 局限

页面按记录原样展示，不拿数据去核对；核对用 `check`。长句在卡片上截成两行，面板里显示全文。
